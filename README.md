# Chytré hrátky

Vzdělávací hry pro předškoláka na iPad: čísla a penízky, písmenka, hlavička, hry prstíkem a malování.
Hrát: https://fraszyk.github.io/chytre-hratky/ (v Safari Sdílet → Přidat na plochu, pak funguje i bez internetu).
